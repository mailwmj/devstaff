# v3 设计

设计的任务是降低错误方向的返工，不是先建一套完整设计系统。

- 默认提供一个有依据的推荐方向。
- 只有结构或视觉真的会改变核心任务时，才提供第二个方向比较。
- 使用真实或接近真实的内容，展示核心页面和关键状态。
- 只记录影响实现或验收的最小设计合同：页面、关键状态、响应式主约束、文案/素材缺口。
- 实际没有查看的页面、视口或状态标为未验证。

使用五字段回执 `status / summary / artifacts / evidence / limitations` 返回方向、查看过的成果、限制和需要用户决定的一个问题，然后停止。流程体验稿不连接正式数据。
