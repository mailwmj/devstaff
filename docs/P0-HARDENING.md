## 已修改的行为

### 检查报告

`check.py` 从项目状态读取模式。报告必须匹配项目模式，不能自行把 strict 降为 guided；必须检查哪些轴也由项目模式和合同决定。

没有状态文件的独立检查保留 guided 默认值。已经存在但损坏、模式未知、版本不支持或存在多个候选状态文件时，不再悄悄降为 guided。

`independent` 只接受 JSON 布尔值。字符串 `"false"`、数字、对象等不再被真值转换当成独立验证。`observed` 必须为非空字符串；`evidence`、`limitations` 必须为非空字符串的列表。字段合法仍不证明证据真实，独立检查仍由宿主执行能力保证。

必须检查的轴中，`blocked`、`not_run` 或缺失优先于 `limited`；未执行核心任务的报告不能靠另一条 limited 变为可交付。合法的 guided limited 报告继续支持。预览与正式可用产品的交付类型分离不在本补丁中。

### 验证轮

`state.py verify` 在接收报告前，重新比较当前合同/源码与本轮 handoff 指纹；读取报告后再检查一次是否发生源码变化。修改过版本后生成新报告，也不能沿用旧轮次交付。

这是变更检测，不是文件系统锁、操作系统沙箱或完整并发事务。不能宣称其他进程无法写入，也不能证明检查期间从未发生过短暂修改。不可变验证快照与更严格的报告读取事务在后续任务中处理。

状态版本必须为支持的整数值。未知 schema_revision 不再落入旧版免门禁路径。prebuild 报告只有 `passed: true` 才表示通过。

### 安装与升级

安装器现在把公共协议复制到：

```text
<安装目录>/site-builder/references/AGENTS.md
```

返回的 `instruction_file` 指向这份已安装文件，不再依赖原始下载/解压目录。宿主仍需加载该路径的协议；这次没有实现所有宿主的自动注册。安装器不覆盖宿主自己已有的 `AGENTS.md`。

升级先暂存完整新版本，再备份并替换技能目录。普通文件操作异常会尝试回滚；回滚失败时保留备份、`recovery.json` 和锁，输出人工恢复位置。增加来源路径、目标重叠和符号链接检查。

四个目录的切换不是一次原子操作。升级前应停止使用这套技能的进程。进程被杀或掉电时不能保证自动恢复；不要盲删锁，应先检查暂存目录、备份与 recovery.json。本补丁不把这些边界包装成“事务完全安全”。
