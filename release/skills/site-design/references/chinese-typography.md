# 中文排版与配色规范（Chinese Typography）

> 本文件是 `site-design` 针对**中文界面、中西文混排及中国本地化场景**的专项排版与视觉规范。
> 来源参考：W3C 中文排版需求（clreq）、Apple HIG 中文版、Ant Design 设计体系与开源排版指北。凡界面包含中文，本文件规则优先级高于通用英文字体规则。

---

## 1. 字体加载与选用纪律（第一硬规则）

**整包引入中文 Webfont 是主要风险，不是"加载外部字体"本身。**
单个中文字体全量文件动辄 5～20MB（系统宋体 Songti.ttc 实测 63.8MB），远大于西文字体。自己托管整包、或不做子集化就引入，会阻塞首屏关键渲染路径并造成布局抖动（CLS）。两条实测结论用于判断，不要把"外部"当成同义词：

- **Google Fonts 对 CJK 已按 `unicode-range` 自动切片**（Noto Serif SC 实测 101 片，CSS 本身 31KB gzip，浏览器只下载页面用到的 3～8 片，约 90～240KB）；显式 `text=` 子集化更小（32 字实测 8.7KB）。
- **`fonts.googleapis.com` 在中国大陆不可靠**。可达性是独立风险，与体积无关：面向大陆受众时，任何承担阅读或主任务的字体都不应只挂在境外 CDN 上。

1. **默认规则：中文一律优先使用系统字体栈**（零下载体积、渲染最锐利、原生操作系统优化）：
   ```css
   font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB",
                "Microsoft YaHei", "Noto Sans SC", sans-serif;
   ```
2. **中文界面的“个性”不靠堆中文字体包**：
   通过**西文/数字展示字体**（体积小、可自由加载，但同样要配系统栈回退）、**中文字阶与字重层次对比**、**网格留白节奏**以及**高质感配色**来实现。
3. **装饰中文字体的例外**：
   - 仅限**营销/品牌落地页的 Hero 短标题**或**用户明确要求的特定书法/复古气质**；
   - 必须满足**字符级子集化（Subsetting）**：只加载标题包含的具体汉字，将体积压缩至几 KB，并配置 `font-display: swap` 与系统栈回退。Google Fonts 的 `text=` 参数是最快路径：
     ```html
     <link href="https://fonts.googleapis.com/css2?family=Ma+Shan+Zheng&text=每场会议都值得铭记&display=swap" rel="stylesheet">
     ```
     面向大陆受众时改为自托管该子集，并在回退栈下确认标题仍然成立。
4. **正文、表格与交互 UI 控件默认使用系统字体栈**，但这不是无条件禁令——满足全部条件时可为正文加载中文字体：
   - 页面文案基本固定（品牌/营销单页；高频变动的动态内容不适用，无法预先子集化）；
   - **自托管子集化字体**（按实际用字产出，百字级约几十 KB），**不依赖境外 CDN**；
   - 配 `font-display: swap` 与完整系统栈回退，断网时正文可读、版式不破；
   - 按 [设计 token](design-tokens.md) 记入合同素材地图。
   **无条件的红线只有一条：不做子集化的整包引入**（思源黑体/宋体 Noto Sans/Serif SC 全族、系统字体全量自托管）始终违规。

## 2. 汉字字重陷阱（避坑防伪粗体）

- **多数中文字体只有 400（Regular）和 700（Bold）两个物理字重**，缺乏西文丰富的中间字重；
- **苹方（PingFang SC）没有原生 700 Bold**：若声明 `font-weight: 700` 或 `font-weight: bold`，部分浏览器引擎会使用合成算法产生“伪粗体”，导致汉字笔画交叠处发黑发糊、边缘发虚；
- **规范标准**：
  - 中文正文一律使用 `font-weight: 400`；
  - 标题、表头与强调文字使用 `font-weight: 500` 或 `600`，**严禁写裸 `bold`**；
  - 信息层级主要依靠“字号尺度 + 颜色明度”拉开，字重仅做辅助区分。

## 3. 中文排版参数与度量

| 排版项 | 规范标准 | 核心设计原理 |
| :--- | :--- | :--- |
| **正文字号** | Web 端正文 $\ge$ 14px（高密度阅读区建议 16px）；移动端 $\ge$ 16px/17pt | 汉字结构方块且笔画复杂，小于 14px 笔画易粘连 |
| **正文行高** | **1.5 ～ 1.75**（暗色背景建议 1.75 ～ 1.8） | 汉字充满字面框，西文常用的 1.3～1.4 行高会导致汉字上下顶头，压抑窒息 |
| **字间距** | 正文 `letter-spacing: 0`；标题可 +0.02em ～ +0.05em；**严禁负字距** | 汉字字身自带等宽方块间距，西文负字距压缩会造成文字重叠黏连 |
| **行长控制** | 桌面端连续正文 28～42 字，移动端 18～25 字（`max-width: 36em` / `36ic`） | 超长行长导致用户换行寻焦疲劳，破坏阅读韵律 |
| **段落间距** | 段底边距 `margin-bottom: 1em`；Web 界面不使用首行缩进 | 现代 Web 界面依托清晰的垂直节奏，首行缩进增加视觉噪点 |

## 4. 盘古之白与标点规则（去 AI 翻译感）

这一节只管标点、空格和字形。句式、用词上的 AI 味（抬高、凑三、大词、复述）按 `AGENTS.md` 的《说人话》改，不要在这里另立一套规则。

### 盘古之白（中西文混排规范）
汉字与西文字符在字形和基线上存在结构差异，混排时必须保持呼吸间距：
- **中文与英文之间**保留 1 个半角空格：`在 GitHub 上查看源码`；
- **中文与阿拉伯数字之间**保留 1 个半角空格：`总计 500 项记录`；
- **数字与单位符号之间**保留 1 个半角空格：`容量 20 TB`；（**例外**：百分比 `15%`、角度 `90°` 与货币符号 `¥99` 不加空格）；
- **全角标点符号与中英文字符之间**不加空格。

### 标点与字形禁令
- **必须使用全角中文标点**（，。？！：；“”‘’），中文句子内严禁夹杂英文半角标点（, . ?）；
- **破折号禁令（Dash Ban）**：严禁在标题、标签、按钮、微文案中滥用西文破折号 `—`（em-dash）与 `–`（en-dash）替代中文标点；普通连接线仅限 `-`（短横线用于区间与版本）；
- **标点不叠用**：禁止感叹号/问号叠用（如“！！！”、“？？？”）；
- **中文严禁斜体（Italics Ban）**：**中文字形库根本没有西文“斜体（Italic）”的设计**。CSS 中使用 `font-style: italic` 会触发浏览器算法强行倾斜笔画，导致汉字重心失衡、结构撕裂变形。中文强调只允许通过字重（500/600）、下划线（仅限链接）、颜色反差或底色胶囊来表达。

## 5. 中文界面色彩与暗色模式 AAA 防线

- **浅色背景层级**：
  - 主标题/正文：`rgba(0, 0, 0, 0.88)`（避免生硬纯黑 `#000`）；
  - 次要/辅助文本：`rgba(0, 0, 0, 0.65)`；
  - 弱提示/占位符：`rgba(0, 0, 0, 0.45)`；
  - 禁用文本：`rgba(0, 0, 0, 0.25)`；
- **暗色背景防线（AAA 级 7:1 对比度）**：
  - 汉字笔画密集，在暗底上若光度不足极易因光学晕映糊成一团。西文 4.5:1 的对比度对复杂汉字并不足够；
  - 暗色背景下中文正文对比度必须达到 **7:1（AAA 级）**，正文推荐使用柔和的 `rgba(255, 255, 255, 0.85)`（降低纯白炫光），次要文字**不得低于** `rgba(255, 255, 255, 0.60)`。
- **中国传统色点缀**：
  - 品牌与营销落地页可适度提取中国传统色作为点缀色彩角色（如朱砂 `#C0392B`、松花绿 `#3B7A57`、靛青 `#1A3A4A`、琉璃黄 `#F0C040`），但底层中性色骨架与控件基底依然保持克制稳定。

## 6. 表格、数据与财务数字

- 界面中的数字一律使用半角 ASCII，严禁使用全角数字（如 `１２３`）；
- 表格列、金融价格、统计仪表盘指标卡强制启用等宽数字对齐：
  ```css
  font-variant-numeric: tabular-nums;
  ```
- 大数字展示可独立引入西文等宽字体（体积仅数十 KB），与系统中文字体组合使用：
  ```css
  .metric-value {
    font-family: "SF Pro Display", "Roboto Mono", ui-monospace, monospace;
    font-variant-numeric: tabular-nums;
  }
  ```

## 7. 中文交付审查清单（Checklist）

- [ ] 中文正文与交互 UI 严格使用系统字体栈；装饰中文字体仅出现在标题且完成字符子集化（`text=...`）；
- [ ] 正文字号 $\ge$ 14px，行高保持在 1.5 ～ 1.75 之间；标题字间距 $\ge$ 0，无负字距；
- [ ] 严格遵循“盘古之白”：中英文与数字之间保持半角空格，全角标点前后无空格；
- [ ] 全文使用全角标点，消灭西文破折号（`—` / `–`），杜绝叠用标点；
- [ ] 全站中文文本绝对无 `font-style: italic` 斜体；
- [ ] 苹方/中文字重仅使用 400（正文）与 500/600（标题），无发虚伪粗体；
- [ ] 暗色背景下中文正文满足 AAA 级对比度（$\ge$ 7:1），避免眩光纯白与发灰死字；
- [ ] 数字、价格与表格列启用 `font-variant-numeric: tabular-nums`。
