# 轻量研究

研究只用于降低会改变首版的事实不确定性，不扩展成行业报告或功能灵感清单。

## 触发条件

以下情况才查证：

- 用户给出网站、截图、文档或现有项目作为依据；
- 法规、平台能力、公开数据、竞品实际流程等外部事实会改变范围或风险；
- 用户把推测当成事实，而它会影响核心场景。

纯产品取舍由用户决定，不能用搜索结果替代确认。无需外部事实即可继续时，直接澄清。

## 最短路径

1. 先写清要验证的问题，以及不同答案会改变什么。
2. 优先读取用户提供材料和项目源码；外部事实优先官方文档、法规原文、产品实际页面等一手来源。
3. 只收集足以回答当前问题的证据；记录来源链接、查看日期和适用条件。
4. 将结论标为：已证实事实、仍不确定、或与当前理解冲突。
5. 把影响翻译为普通语言，更新 brief 中的事实、假设或待确认项；外部事实不得写进“已确认决定”。

## 与设计参考的边界

本 Skill 只调查会改变业务范围、风险和可行性的事实。截图、网页的布局、视觉和交互参考由 `site-design` 观察并区分还原、借鉴或功能相似；不要在两个 Skill 中重复分析同一视觉资料。引用页面展示的功能不等于首版必须包含。

## 输出

默认在对话或 `.site/brief.md` 对应条目旁给出简短来源，不另建研究报告。只有用户明确要求独立报告时才创建。无法访问、来源互相冲突或时效未知时如实保留不确定性，不用 Agent 常识补成事实。
