# 按需分发升级

先识别“发给别人”：看内容、各自独立运行、多人共享同一份数据。不要把三者都当上传静态文件。

从现有页面操作、业务函数、字段和真实/模拟能力提取差距。共享使用按需补身份、权限、并发、持久化、迁移和备份；保持可用的接口和视觉，不承诺仅换地址或替换一个文件。

使用当前环境已有且适合目标的发布能力；本技能未内置云平台部署器。用户已经授权的工作继续做，新增付费、账号授权、公开内容等实际决策才请求确认。没有合适能力时完成可转交产物并解释具体缺口，不假装已经发布。

发布后实际检查访问入口和核心任务，确认数据迁移结果。发布命令成功不等于业务验收。独立分发还要验证接收端的安装、启动和数据隔离。
