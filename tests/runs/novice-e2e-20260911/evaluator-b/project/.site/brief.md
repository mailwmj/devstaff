# 项目 brief

## 要解决的问题
- 创作者为什么要做这件事：让家长在报名咨询前，清楚了解周末自然观察课的内容、适龄范围、时间安排与安全边界。
- 最终用户与使用场景：小学阶段孩子的家长，在手机或电脑上第一次了解课程并决定是否发起咨询。

## 完整愿景
建立一个可信、具体、有自然气息的课程介绍入口，之后可继续承载真实开课日期、集合地点、报名名额和课后观察记录。

## 首个可验证版本
- 核心任务：家长打开页面后，在几分钟内判断课程是否适合自己的孩子，并生成一段咨询信息。
- 完成后的可观察结果：家长能看到课程内容、一次周末如何进行、适龄与安全说明；点击“发起咨询”后，填写少量信息并获得可复制的咨询文本。
- 包含：单页课程介绍、课程主题、周末流程、适龄/安全说明、FAQ、咨询表单与本地成功反馈。
- 暂不包含：在线支付、账号、报名名额管理、云端保存、家长评价、儿童照片上传、真实地图与通知系统。

## 核心场景
家长在周末前第一次看到课程页面，先了解孩子会观察和记录什么，再查看一次活动的时间安排与安全边界，最后输入称呼、孩子年级和想咨询的周末，点击生成咨询内容，看到一段可以复制到微信或短信里的文字。若暂时不确定日期，可以选择“还没想好”，页面仍会生成不带日期的咨询内容。

## 已确认决定
- 采用低风险单页首版，由 Agent 按推荐方案直接推进（依据：用户“你帮我弄一下吧”，2026-09-11）。
- 首版主要服务家长的了解与咨询，不承诺在线报名完成（依据：默认范围，2026-09-11）。

## 已知事实
- 课程由一位小学老师在周末带领。
- 主题是自然观察课。
- 面向家长了解课程。

## Agent 假设
- 使用中文、手机优先的单页体验。
- 课程地点暂以“城市公园与校园周边自然空间”作为可替换示例，不写死具体地址。
- 具体日期、价格、联系方式尚未提供，因此用“咨询后确认”，不虚构信息。
- 咨询信息只在浏览器当前页面生成，不提交到服务器。

## 待确认与风险
- 正式上线前需要补充老师姓名/称呼、城市或活动区域、真实日期、费用、集合地点和实际联系方式。
- 面向未成年人，后续若加入报名、照片或长期记录，需要重新确认数据保存、家长授权与隐私边界。
- 当前远程图片来自 Unsplash，正式发布前应替换为自有课程照片或确认图片授权。

## 体验稿要回答的问题与选定方向
- 待回答的问题：家长是否能顺着“课程是什么 → 一次怎么进行 → 是否适合 → 如何咨询”完成判断。
- 选定方向与依据：自然观察日志风格的温暖实用单页；用纸张感背景、墨绿色文字、黄色观察标记和一张真实自然活动照片，强调具体行动而非口号。
- 模拟范围：完整首屏、课程主题、时间线、安全说明、FAQ、咨询弹窗与生成结果。
