# 实施计划

## 页面与导航
单页锚点导航：课程内容、周末流程、家长须知。主行动为“发起咨询”，打开咨询对话框；移动端导航收纳为菜单。

## 业务规则
- 咨询表单只要求家长称呼、孩子年级、想咨询的周末；日期可选“还没想好”。
- 提交后在对话框内生成咨询文本，不发送、不存储、不上传。
- 复制按钮使用浏览器剪贴板；失败时仍展示完整文本供手动复制。

## 数据生命周期与外部服务
无后端、无账号、无外部服务。输入仅存在于当前页面 DOM 和生成结果中，刷新后消失。图片为远程 Unsplash 资源。

## 关键状态
默认阅读状态、移动导航展开、咨询对话框打开、表单校验提示、咨询文本生成完成。

## 技术选择
原生 HTML、CSS、JavaScript，静态文件可由任意静态服务器提供。

## 实施顺序
1. 完成课程介绍与响应式页面结构。
2. 完成移动导航与咨询生成交互。
3. 用构建/静态服务检查入口、核心点击路径、键盘可达性和移动端布局。

## 可观察完成条件
家长能从首屏进入课程内容、流程和家长须知；咨询表单能阻止缺失必填项，提交后生成包含已填信息的可复制文本；在窄屏上导航、主要按钮和对话框不发生遮挡或横向溢出。
