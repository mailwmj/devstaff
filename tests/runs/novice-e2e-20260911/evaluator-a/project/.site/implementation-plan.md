# 历史实施计划（不适用于本轮）

本文件来自较早方案。本轮创作者尚未确认核心任务、首版范围或开发授权，因此不得按此计划创建正式工程。待需求方案确认后，应重新制定实施计划。


## 页面与导航
- 单页 `web/index.html`，顶部导航锚点指向“课程”“安排”“安心”“关于老师”“咨询”。
- 移动端把导航折叠为可展开菜单，主 CTA 始终可见。

## 业务规则
- 页面只承接了解和咨询意向，不创建报名订单。
- 咨询表要求称呼、孩子年级和兴趣周末；备注可选。
- 提交时在本地显示确认状态，不声称已发送给老师，也不保存儿童信息。
- 用户可重新填写或回到课程内容继续阅读。

## 数据生命周期
- 本轮不写入 localStorage、不上传第三方、不跨设备同步。
- 表单数据只存在于提交事件的当前内存中，刷新页面后消失。

## 角色权限
- 家长：浏览课程并提交咨询意向。
- 老师：本轮没有后台；真实承接方式上线前另行接入。

## 外部服务
- 页面使用公开图片 CDN 作为临时视觉素材。
- 没有登录、支付、地图、邮件发送或真实表单服务。

## 关键状态
- 首次进入：课程内容正常可读。
- 移动导航：展开、关闭、点击锚点后自动收起。
- 咨询表：未提交、必填校验、提交后反馈。
- 无真实联系信息：以示例标识，不把示例当作可用联系方式。

## 技术选择
- 原生 HTML、CSS、JavaScript，无构建依赖。
- 本地启动：`python3 -m http.server 8765 --directory web`。

## 实施顺序
1. 完成首屏、课程内容、流程、安全与老师介绍。
2. 加入咨询表校验和提交反馈、移动导航交互。
3. 做响应式、焦点、减少动效和图片加载兜底。
4. 启动本地预览，检查桌面与移动视口。

## 可观察完成条件
- 家长不需要注册即可从首屏读到课程定位，并通过锚点到达咨询区。
- 课程内容、流程、安全、老师信息在桌面和移动端均可读。
- 咨询表提交后反馈明确，未声称远程发送成功。
- 重新打开页面后没有伪造的历史咨询或残留儿童信息。
