# 本轮恢复说明（2026-09-11）

创作者本轮原话是：“我是小学老师，想做个网站让家长了解我周末带的自然观察课，但我还没想清楚要做哪些东西。你帮我弄一下吧。”

本轮只确认了：创作者是小学老师，周末带自然观察课，希望做一个让家长了解课程的网站。下方原有内容来自较早的方案记录；其中关于单页结构、咨询表、示例资料、视觉方向和开发授权的内容，本轮均视为历史假设，不能当作当前决定。待创作者回答需求发现问题并明确认可首版方案后，才能恢复下游设计或开发流程。

## 当前前沿

- 核心用户：待确认是家长直接浏览，还是还包括学校/其他照护者等对象。
- 核心结果：待确认家长最重要的是了解课程、判断是否适合，还是完成咨询/报名等动作。
- 首版边界：待确认是否只做介绍页，是否需要报名、日历、照片、联系方式或其他功能。
- 现实约束：待确认课程年龄、地点、时间、费用、人数、安全安排和承接咨询方式。


## 要解决的问题
- 创作者为什么要做这件事：让家长快速了解周末自然观察课，建立对课程内容、带队方式和安全安排的信任，并能方便地发起咨询。
- 最终用户与使用场景：家长在手机或电脑上浏览周末安排，判断课程是否适合自己的孩子，再联系老师询问名额与细节。

## 完整愿景
一个温和、可信、可持续更新的自然观察课介绍站。未来可以继续承接每期活动日历、报名、家长须知、照片回顾和通知，但首版先解决“看懂课程并愿意咨询”。

## 首个可验证版本
- 核心任务：家长读完课程介绍后，能判断孩子是否适合参加，并通过咨询入口表达兴趣。
- 完成后的可观察结果：家长能在同一页面找到课程内容、适合年龄、周末安排、安全说明、老师信息与咨询入口；提交咨询表后看到明确的确认反馈。
- 包含：单页介绍、课程亮点、一次典型周末流程、适合人群、带队与安全说明、老师介绍、咨询表、移动端适配。
- 暂不包含：登录、在线支付、真实订单、云端报名数据、家长社群、地图导航、未成年人长期档案和照片上传。

## 核心场景
家长在周末前看到课程链接，先了解孩子会观察什么，再查看时间、年龄和安全安排，最后填写称呼、孩子年级和感兴趣的周末；提交后看到“已收到咨询”的反馈，并知道正式上线前需要接入真实联系方式或表单服务。
若家长暂时不确定，则可以直接跳到常见问题或返回课程内容继续阅读，不要求先注册或提交个人信息。

- 使用真实户外观察照片作为页面主视觉，内容结构围绕家长判断顺序展开。（Agent 方向判断，待上线素材替换）
